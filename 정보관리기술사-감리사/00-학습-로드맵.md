# 정보시스템감리사 집중 학습 로드맵

> **현재 목표: 정보시스템감리사 합격 준비에만 집중한다.** 2026-11-10 사용자 결정에 따라 기술사 병행 및 기사 범위 우선 전략을 중단했다. 기존 폴더명은 링크와 기록 유지를 위해 보존한다.

[[정보처리기사/07-학습-진도|학습 진도]]의 다음 학습 지점에서 이어간다. [[정보처리기사/00-학습-허브|학습 허브]]는 기존 개념 노트의 목차다.

## 범위와 우선순위

감리사 필기 5과목인 **감리 및 사업관리, 소프트웨어공학, 데이터베이스, 시스템구조, 보안**을 학습 축으로 삼는다. 기사·기술사와의 교집합에 한정하지 않고 감리사 고유 범위도 포함한다. 세부 범위와 우선순위는 감리사 공식 안내와 공개 기출을 대조해 정한다. 실제 응시를 결정할 때 일정·자격·절차는 최신 공고로 확인한다.

| 학습 축 | 주요 내용 |
|---|---|
| 감리 및 사업관리 | 감리 기준·절차·산출물, 시정조치 확인, 범위·일정·비용·위험·품질·조달 관리 |
| 소프트웨어공학 | 개발 생명주기·방법론, 요구사항·UML·설계·아키텍처, 테스트·품질·형상관리 |
| 데이터베이스 | 모델링·정규화·SQL·인덱스, 트랜잭션·동시성·복구·데이터 관리 |
| 시스템구조 | 컴퓨터 구조·운영체제·네트워크, 분산·클라우드, 성능·가용성·재해복구 |
| 보안 | 인증·접근 통제·암호, 시스템·네트워크·애플리케이션 보안, 개인정보 및 관련 기준 |

위 표는 학습용 분류이며 공식 세부 출제범위를 모두 열거한 체크리스트는 아니다. 기존 [[01-공식-기출-교집합-분석|기술사·감리사 기출 교집합 분석]]은 과거 참고 자료이며 현재 학습 범위를 제한하는 기준으로 사용하지 않는다.

## 진행 방식

1. 별도 복습 없이 진도 노트의 다음 지점에서 시작한다. 복습은 사용자가 별도로 진행한다.
2. 한국어로 개념과 작동 원리, 유사 개념과의 차이를 설명한다.
3. 사례에 적용해 위험·확인 자료·판단 기준·개선안을 연결한다. 모든 기술 주제를 감리 절차 문제로만 바꾸지 않고 과목 자체의 원리와 계산·적용 문제도 다룬다.
4. 감리사 객관식에서 정답의 근거와 다른 선택지가 부적절한 이유를 설명하도록 연습한다. 문제를 낸 뒤에는 사용자 답을 기다린다.
5. 기술사식 5~8줄 답안이나 통합 논술 단계는 추가하지 않는다. 짧은 서술은 이해와 판단 근거 확인에 필요한 만큼만 사용한다.

짧게 공부하는 날에도 개념→사례 또는 객관식 판단→피드백 순서로 한 주제를 진행한다. 이미 다룬 사실을 숙달로 간주하지 않고, 추천 답변을 사용한 경우 독립 수행과 구분한다. 학습 후 확인된 혼동과 다음 지점을 기록한다. 예약 자동화는 만들지 않는다.

## 바로 다음 학습

현재는 소프트웨어공학의 변경 영향 분석과 회귀 테스트 대상 선정을 학습했다. 할인 계산→최종 결제 금액→환불의 간접 영향 판단, 감리 확인 자료, 영향 분석·테스트 보완 및 결과 확인까지 다뤘다. 미응답 기술사식 통합 서술은 현재 과정에서 제외한다. 다음은 **위험 기반 회귀 테스트 우선순위 선정**을 감리사 사례·객관식 판단으로 이어간다. 세부 상태는 [[정보처리기사/07-학습-진도|학습 진도]]를 따른다.
