# 정보처리기사 학습 로드맵

> **현재 목표: 정보처리기사 준비에 집중한다.** 2026-11-24 사용자 요청으로 감리사 중심 학습에서 변경했다. 기존 폴더명과 학습 기록은 링크 유지를 위해 보존한다.

[[정보처리기사/07-학습-진도|학습 진도]]의 다음 학습 지점에서 이어간다. [[정보처리기사/00-학습-허브|학습 허브]]는 기존 개념 노트의 목차다.

## 범위와 우선순위

정보처리기사의 개념 이해와 문제 적용을 중심으로 진행한다. 이미 다룬 SQL·정규화·C·Java·운영체제·설계·테스트·네트워크 기록을 이어 쓰며, 처음부터 다시 시작하거나 다룬 내용을 숙달로 간주하지 않는다. 응시 연도의 세부 범위·과목·일정이 필요하면 최신 공식 출제기준과 공고를 확인한다.

| 학습 주제 | 주요 내용 |
|---|---|
| 소프트웨어 설계·개발 | 요구사항·UML·설계, 개발 방법론, 테스트·품질·형상관리 |
| 데이터베이스 | 모델링·정규화·SQL·키·인덱스, 트랜잭션·동시성·복구 |
| 프로그래밍 언어 | C·Java·Python의 코드 해석과 기본 자료구조·알고리즘 적용 |
| 운영체제·네트워크·보안 | 프로세스·스케줄링·메모리, IP·서브넷·프로토콜, 접근 통제·암호 |

위 표는 학습용 주제 분류이며 공식 과목명이나 전체 출제범위 목록은 아니다. 기존 [[01-공식-기출-교집합-분석|기술사·감리사 기출 교집합 분석]]은 과거 참고 자료로 보존한다. 감리사 전용 범위와 기술사 답안 훈련은 현재 학습의 필수 과정에 넣지 않는다.

## 진행 방식

1. 별도 복습 없이 진도 노트의 다음 지점에서 시작한다. 복습은 사용자가 별도로 진행한다.
2. 한국어로 개념과 작동 원리, 유사 개념과의 차이를 설명한다.
3. 같은 개념을 기사 수준의 객관식·계산·코드 해석·단답 문제에 적용한다. 문제를 낸 뒤에는 사용자 답을 기다린다.
4. 답변에 따라 정답의 근거와 오답 선택지·계산 과정의 혼동을 설명한다. 근거 설명의 길이는 이해 확인에 필요한 만큼으로 조절한다.
5. 감리 자료 작성이나 기술사식 통합 논술 단계는 필수로 추가하지 않는다. Python 경험과 C·Java 기초 수준을 고려해 새 언어 개념을 설명한다.

짧게 공부하는 날에도 개념→문제 적용→피드백 순서로 한 주제를 진행한다. 이미 다룬 사실을 숙달로 간주하지 않고, 설명만 한 경우와 독립 적용을 구분한다. 학습 후 확인된 혼동과 다음 지점을 기록한다. 예약 자동화는 만들지 않는다.
