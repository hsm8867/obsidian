# 학습 진도

> [!info] 다음 대화의 시작점
> **정보처리기사 필기 객관식**을 이어간다. 최근에는 프로세스·스레드와 CPython GIL의 차이를 확인했다. 다음에는 **운영체제 메모리 관리**(가상 메모리·페이징·페이지 부재·스래싱)를 객관식 5문제로 시작한다. 필요하면 라운드 로빈과 GIL을 먼저 한 문장씩 복습한다.

## 목표와 학습 방식

- 우선 목표: 정보처리기사 필기. 장기 목표: 정보관리기술사 합격.
- 객관식 문제를 풀고 채점·해설을 받은 뒤 다음 문제로 진행한다.
- Python은 사용 경험이 있고 C·Java는 기초 수준이다. 새로운 프로그래밍 개념은 Python과 비교하면 이해에 도움이 된다.
- 아래 목록의 **다룸**은 **숙달**을 뜻하지 않는다. 점수나 합격 가능성은 기록된 근거 없이 추정하지 않는다.

## 다시 확인할 개념

사용자가 직접 어렵거나 헷갈린다고 밝힌 부분만 기록한다. [[06-오답-복습]]의 모든 항목이 실제 오답이라는 뜻은 아니다.

- **정규화:** 1NF·2NF·3NF가 직관적으로 와닿지 않아 전체 설명과 시각화를 요청했다.
- **인덱스:** 조회·삽입/삭제의 성능 차이는 알고 있었지만 주관식 정의를 어떻게 쓸지 어려워했다.
- **라운드 로빈:** 개념을 모르고 찍어서 맞혔다고 밝혔다.
- **스레드와 GIL:** Python이 프로세스당 스레드 하나만 쓰는지 혼동했다.
