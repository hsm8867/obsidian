# 2026-10-27 학습

[[07-학습-진도]] · [[05-운영체제와-네트워크]] · [[06-오답-복습]]

## 오늘 다룬 내용

- 가상 메모리, 페이징, 페이지 내부 변위, 페이지 부재, 스래싱 객관식 5문제 중 **1문제 정답**(가상 메모리의 목적).
- 페이징·페이지 부재 문항에서 오답을 확인했다. 변위 비트 수와 스래싱 문항은 모른 채 찍었다고 밝혔다.
- 이어진 확인 문제 3개는 **모두 정답**이었다: 8 KiB의 변위 13비트, 유효한 페이지의 페이지 부재, 스래싱의 정의.
- 페이징의 작동 원리를 자세히 설명해 달라고 요청해 **페이지·프레임, 페이지 테이블, 주소 변환, 페이지 부재, 장점과 비용**을 예시로 정리했다.
- 주소 변환 적용 문제에서 **③ 6596**을 선택해 맞혔고 풀이 설명을 요청했다. `2500 = 2 × 1024 + 452`에서 페이지 2를 프레임 6으로 바꿔 `6 × 1024 + 452 = 6596`을 구하는 과정을 확인했다.
- FIFO·LRU의 교체 기준과 적중 시 기록 차이를 소개했다. 관련 객관식 3문제 중 **1번 FIFO 교체 대상만 정답**, **2번 LRU 교체 대상과 3번 페이지 부재 횟수는 오답**이었다. 이전에 제출한 1·2번을 다시 적은 것은 중복 집계하지 않는다. 참조 `1 → 2 → 3 → 1 → 4 → 1`을 표로 추적해 **FIFO 5회, LRU 4회**를 설명했다.
- 사용자가 **부재와 적중의 개념 자체가 헷갈린다**고 밝혀, 요청 직전 RAM에 해당 페이지가 있는지로 판정하는 과정을 다시 설명했다. 프레임 1개에서 `1 → 1 → 2`의 부재 2회·적중 1회·교체 1회를 비교했다.

## 핵심 정리

- 페이징은 **고정 크기 페이지와 같은 크기의 프레임**을 사용한다. 가변 크기 세그먼트는 세그먼테이션이다.
- 4 KiB는 `4096 = 2^12`바이트이므로 바이트 단위 **페이지 내부 변위는 12비트**다.
- 유효한 페이지가 메모리에 없으면 **페이지 부재**가 발생한다. 유효하지 않은 주소 접근과 구분한다.
- **스래싱**은 잦은 페이지 교체·입출력 때문에 실제 작업이 느려지는 상태다. TLB 적중은 최근 주소 변환 결과를 찾는 것이다.
- **페이지 테이블**이 가상 페이지 번호를 물리 프레임 번호로 바꿔 준다. 페이지 내부 변위는 그대로 유지된다. 자세한 계산 예시는 [[05-운영체제와-네트워크#주소 변환: 페이지 번호만 바뀐다]].
- FIFO·LRU 예시에서 4를 넣을 때 FIFO는 1을 내보내지만, LRU는 2를 내보내고 최근에 사용한 1을 남긴다. 따라서 마지막 1은 **FIFO에서는 부재, LRU에서는 적중**이다.
- **적중/부재는 요청 직전 RAM 상태로 판단**한다. 페이지를 새로 넣은 뒤 RAM에 있어도 그 접근은 부재다. 빈 프레임이 있으면 부재를 처리할 때 기존 페이지를 내보낼 필요가 없다.
