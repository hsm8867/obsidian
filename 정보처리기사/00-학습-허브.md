# 학습 허브

> [!info] 학습 방향
> 현재는 **정보시스템감리사 합격 준비에만 집중**한다(2026-11-10 변경). 감리사 필기 5과목과 기출을 기준으로 개념·사례·선택지 판단을 학습한다. [[정보관리기술사-감리사/00-학습-로드맵|학습 로드맵]]을 따른다. 기존 폴더명은 기록과 링크 유지를 위해 보존한다.

## 공부 방식

1. 별도 복습 없이 [[07-학습-진도|다음 진도]]에서 시작한다. 복습 노트는 사용자가 별도로 활용한다.
2. 개념·원리와 유사 개념의 차이를 이해하고 사례에 적용한다.
3. 감리 관점의 위험·확인 자료·판단 기준·개선안으로 연결한다.
4. 감리사 객관식의 정답 근거와 오답 선택지가 부적절한 이유를 설명한다. 기술사식 답안 훈련은 추가하지 않는다.
5. 한 번 다룸·추천 답변 활용·독립적인 적용을 구분하며 숙달을 단정하지 않는다.
